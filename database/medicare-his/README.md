# MediCare HIS — SQL Server

Mở `MediCare_HIS_File.sql` bằng SQL Server Management Studio, kết nối SQL Server 2019/2022 và chạy toàn bộ bằng F5. File này gộp schema, dữ liệu demo và truy vấn kiểm tra.

Chi tiết thiết kế và giới hạn: [README_MediCare_SQL.md](README_MediCare_SQL.md).

Đây là bộ cơ sở dữ liệu MediCare độc lập. Việc thêm các file SQL vào repository chưa kết nối hoặc thay đổi backend của website hiện tại. Đã kiểm tra cú pháp bằng ScriptDom; chưa thực thi trên SQL Server.
